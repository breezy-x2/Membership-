# Library Membership System

A library website for Greenview College, built as a group project. I built the **membership** part of the system.

## What my part does
1. The student clicks **Apply for membership** from the library homepage
2. **Verify student ID:** the system checks the database and, if the student is registered, shows their name, course and year
3. **Choose a plan:** Basic, Gold or Platinum
4. **Activate membership:** the student confirms and the membership is saved
5. A digital membership card is shown and can be saved

Payment is not included in this version.
- They receive a digital membership card
- They can view their membership details via dashboard

## Built with
- HTML
- CSS
- PHP
- MySQL

## How to run
1. Install XAMPP and start Apache and MySQL
2. Copy the project folder into `htdocs`
3. Open phpMyAdmin and import the database file
4. Go to `http://localhost/your-folder-name` in your browser
